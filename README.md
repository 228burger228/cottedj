# Да — Архитектура & Дом

Сайт компании по строительству каменных коттеджей и загородных резиденций под ключ.

## 🚀 Возможности

- ✅ Полный цикл строительства (от проекта до ландшафта)
- ✅ Фиксированная смета без скрытых расходов
- ✅ 24/7 видеонаблюдение стройплощадки
- ✅ Более 140 сданных домов
- ✅ 25 лет гарантии на конструктив
- ✅ Собственная производственная база

## 🛠️ Технологический стек

- **Frontend:** React 19 + Vite 6
- **Styling:** Tailwind CSS 4 + custom theme
- **Icons:** Lucide React
- **Build Tool:** Vite with React plugin
- **Typography:** Inter font from Google Fonts

## 📋 Структура проекта

```
src/
├── components/
│   ├── Header.jsx          # Навигация с фиксированным позиционированием
│   ├── Hero.jsx            # Основной баннер с фоновым изображением
│   ├── Directions.jsx      # Направления строительства
│   ├── Projects.jsx        # Каталог типовых проектов
│   ├── Quiz.jsx            # Интерактивный форма-опрос
│   ├── About.jsx           # О компании
│   ├── Architecture.jsx    # Архитектурное бюро
│   ├── Steps.jsx           # Этапы строительства
│   ├── WinterOffer.jsx     # Зимняя акция
│   ├── Portfolio.jsx       # Портфолио объектов
│   ├── Investors.jsx       # Для инвесторов
│   ├── Geography.jsx       # География работ
│   ├── Articles.jsx        # Полезные статьи
│   ├── ContactForm.jsx     # Контактная форма
│   └── Footer.jsx          # Подвал сайта
├── App.jsx                 # Главный компонент приложения
├── main.jsx                # Entry point
└── index.css               # Tailwind + кастомная тема

public/
├── images/                 # Все изображения проекта
├── favicon.svg             # Логотип в браузере
└── index.html              # HTML шаблон
```

## 🚀 Запуск проекта

### Установка зависимостей
```bash
npm install
```

### Запуск dev сервера
```bash
npm run dev
```
Сервер будет доступен на `http://localhost:5173/`

### Production build
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```
